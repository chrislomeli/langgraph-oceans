
Oceanographic & Environmental DataTo track Sea Surface Temperature (SST), chlorophyll levels, and salinity, you can query global environmental data servers.NOAA ERDDAP (Environmental Research Division's Data Access Program)What it provides: Global, high-resolution satellite gridded data for daily Sea Surface Temperature (SST) and Chlorophyll-a.How to access programmatically: The NOAA ERDDAP Server allows you to request specific spatial-temporal subsets directly via REST URLs. You pass your coordinates and dates into the URL, and it returns data in JSON, CSV, or NetCDF format.Copernicus Marine Service (CMEMS)What it provides: Global Ocean Physics Reanalysis and satellite-derived historical ocean data.How to access programmatically: You can use the Copernicus Marine Data Store along with the Copernicus Marine Toolbox Python API. This allows you to write a clean script inside your ingestion pipeline to query daily historical physical variables (like salinity and temperature) back to 1993.2. Bathymetry & Seafloor DataTo calculate if your whale was photographed over a shallow continental shelf or a deep canyon, you need oceanic topographic data.GEBCO (General Bathymetric Chart of the Oceans)What it provides: A continuous, global terrain model for the ocean floor with the highest resolution publicly available.How to access programmatically: You can download gridded datasets directly from the GEBCO Data Download portal or stream requests via OPeNDAP protocols. Once downloaded as a NetCDF or GeoTIFF, you can easily load it into your database using PostgreSQL's PostGIS extension (raster or spatial lookups).3. Spatial Boundaries & Marine SanctuariesTo identify if a sighting happened inside a marine reserve, you can query global protected area polygons.Protected Planet / WDPA (World Database on Protected Areas)What it provides: The most comprehensive global database of marine and terrestrial protected areas managed by UNEP-WCMC and IUCN.How to access programmatically: You can download the global Marine Protected Area (MPA) boundaries as a Shapefile or GeoPackage from the Protected Planet site. You can then load these polygons into Postgres using shp2pgsql and write a PostGIS query using ST_Contains() to see if a sighting coordinate falls within a sanctuary boundary.4. Macro-Ecological & Sighting ContextTo enrich your database with general regional biodiversity and historical tracking records:OBIS (Ocean Biodiversity Information System)What it provides: An integrated global database harvesting millions of marine species occurrence records (in fact, some portions of historic Happywhale data are natively mirrored here).How to access programmatically: Use the OBIS API or their GeoParquet datasets hosted on AWS to mass-analyze regional species density. This helps your RAG agent answer contextual questions like: "Are Blue Whales typically found in this quadrant during this month?"
